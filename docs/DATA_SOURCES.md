# 数据源与分层

> 这一层决定报告的上限。模型再强，来源不行，结论就是空的。
> 原则：**层级由来源决定，不由措辞决定**；未接入就说未接入。

## 1. 五级来源

| 层级 | 定义 | 例子 | 可用作 |
|---|---|---|---|
| **L1** | 官方统计 / 监管公告 | 国家统计局、部委官网、地方统计局 | 宏观与法定事实 |
| **L2** | 法定披露 / 交易所 | 巨潮资讯、SEC EDGAR、上证 e 互动 | 企业侧经营数据 |
| **L3** | 行业机构 / 协会 | 中国连锁经营协会、中国汽车工业协会、券商研报页 | 行业口径与结构 |
| **L4** | 市场发现 / 媒体 | 财经媒体、门户、研究机构新闻稿 | 线索与交叉验证 |
| **L5** | 用户声音 / 社媒 | 社媒、评价、论坛 | 只能作假设来源 |

一条纪律：**L4/L5 不能单独支撑决策区的数字**。可以用来说明"市场上有人这么说"，不能用来当"事实如此"。

## 2. 注册表

`backend/core/source_registry.py` 是唯一登记处。每条 `SourceSpec` 声明：

```python
name          显示名
layer         L1–L5
domains       归属域名（用于核验 URL 是否真的属于该来源）
status        connected / planned
requires_key  是否需要 API Key
probe         健康探针（可选）
```

当前 **17 条：16 条已接入，1 条规划中**。状态由代码自报，`registry_summary()` 直接输出这句话，文档不另抄一份。

已接入的源：

- 官方与监管：国家统计局、政府门户/部委官网、省市统计局、中国政府采购网
- 法定披露：巨潮资讯、SEC EDGAR、上证 e 互动
- 行业机构：中国连锁经营协会（CCFA）、中国汽车工业协会（CAAM）
- 国际组织：世界银行开放数据、IMF World Economic Outlook
- 检索通道：通义千问 `enable_search`、博查搜索 API、Bing 结果页解析（无 key 兜底）
- 研究页与内部资产：券商/研究机构研报页、行业知识库（历史调研沉淀）

规划中：国家知识产权局（官网公告）。

## 3. 路由：不是"全都搜一遍"

`Source Router` 按「维度 × 问题类型 × 可用性」分配源族：

```
industry      → 行业机构 + 研报页 + 统计
competition   → 法定披露 + 行业机构 + 媒体
user          → 社媒 + 评价（只产出假设）
statistics    → 官方统计 + 国际组织
```

三条约束：

1. **白名单**：不在注册表里的域名，不得作为引用来源；
2. **隔离**：子 Agent 只能看到自己那份工具名单，越界即断言失败；
3. **空手而归是合法结果**：拿不到就回传缺口，不允许"用常识补一个"。

## 4. 配额与降级

- 每个维度期望至少 `AUTH_QUOTA_PER_DIM` 条 L1/L2 证据；不足只告警，不改写结论；
- 检索通道有健康探针，失败自动切下一条，并记 `degraded`；
- Bing 结果页解析有滑窗配额（默认 30 次 / 15 分钟）与礼貌间隔（默认 1.2 秒）；
- `AUTHORITY_FETCH_ENABLED=0` 可一键关闭直取源，系统静默降级。

## 5. 时效

每条证据带 `data_period`（数据期）与 `published_at`（发布日期）。当前实现：

- 数据期超过 3 年的条目，只能作为"历史基线"，并在正文标注；
- 同一数据点被重复填入 ≥3 个章节，报"证据集中度"；
- 时效补检的结果必须被正文消费，否则在报告里说明"未消费"。

> 现状：数据期规则目前**只展示、未阻断**（见 [AUDIT_PIPELINE](AUDIT_PIPELINE.md) §8）。这是一处已知缺口。

## 6. 合规与礼貌

- 只访问公开页面，不绕过登录、付费墙或反爬；
- `verify.py` 复探频率 ≥1 秒/主机；
- SEC 要求 User-Agent 带真实联系邮箱（`SEC_UA_CONTACT`），未填写时会在健康检查里告警；
- 引用遵守合理使用范围：摘录 + 出处 + 数据期，不整篇转载；
- 报告标注 AI 生成合成内容标识（`core/ai_label.py`）。

## 7. 为什么不做"全网爬"

三个原因：

1. **可核验性**：来源越杂，复核成本越高，最后变成"只能相信"；
2. **责任边界**：低质源带来的错误，最终由交付方承担；
3. **工程现实**：17 条高质量源已经能覆盖消费、制造、宏观三类问题的主干；把长尾做厚，收益远小于把主干做准。

需要长尾时，走「场景包」：每个场景补 3–5 条专用源（加盟备案、海关、港美股披露），而不是把全网塞进一个索引。

# ADR 0005：证据不足必须写成交付物

## 背景

研究类产品有一个结构性诱惑：把"不知道"写成"大概如此"。用户也更愿意为一份"完整"的报告付费。

但在决策场景里，一个看起来完整的错数，比一个明确的空白更贵。

## 决定

报告必须包含三层缺口披露：

1. **Known**：有来源、可核验的事实；
2. **Estimated**：有推算过程、标注了假设的估计；
3. **Unknown**：当前证据不足，明确写"不够"，并给出补齐路径（查什么源、问什么人、花多少时间）。

结论状态里，"证据不足"是合法终态，不允许为了好看而降级成"较可信"。

## 后果

- 报告可能显得"不完整"，但决策者知道哪块地基是软的；
- 需要在 UI 与导出件里给 Unknown 留位置，不能被折叠掉；
- 销售叙事更难讲——这是刻意接受的成本：卖的是"知道哪里会翻车"，不是"什么都懂"。

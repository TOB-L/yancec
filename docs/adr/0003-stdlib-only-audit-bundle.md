# ADR 0003：审计包复算脚本只用标准库

## 背景

"可复算"最初是一个声明：报告里写"第三方可以重算"，但复算需要安装项目依赖、配置模型 Key、理解内部模块。实际上没人能复算。

## 决定

审计包里的 `compute.py` 与 `verify.py`：

- 只 import Python 标准库；
- 不 import 本项目任何模块；
- 输入只有包内的 `raw/` 与 CSV；
- 输出"声明 vs 复算"的差异表。

## 后果

- 任何人 `python verify.py` 就能跑，不需要环境；
- 复算能力受限于标准库：复杂统计（回归、显著性检验）无法覆盖，只能做 CAGR、同比、占比这类算术；
- 规则必须从运行时常量导出（`rules.md`），否则脚本与规则会漂移。

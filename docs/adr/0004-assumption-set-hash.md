# ADR 0004：用 assumption_set 哈希区分不可比运行

## 背景

同一个引擎版本、同一套提示词，两次运行给出了两套完全不同的单位经济：TAM 4,687 亿 vs 6,026 亿，BEP 222 杯 vs 242 杯。原因是算术确定，但**输入参数是模型每轮挑的 L5 估算**。

这导致"同版本"被误读成"可比较"。

## 决定

对一次运行的全部关键假设做规范化哈希：

```
assumption_set = SHA-256(UE 9 项输入 + TAM/SAM/SOM 6 项输入，按名排序)
```

与 `prompt_set`（提示词哈希）、`engine_version`、`judge_prompt_fp` 并列写入报告头与台账。

**横比规则：只有四项都相同的运行才有资格比较。**

## 后果

- "重跑一次得到不同结论"从缺陷变成可解释的设计：那是另一组假设；
- 不足：哈希只能证明"假设不同"，不能证明"哪组假设更对"；
- 参数来源仍需审计（是模型挑的、配置读的，还是缓存复用的），这是下一版要补的。

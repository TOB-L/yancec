# 示例运行

这里放一次**真实运行**的完整产物，不需要 API Key 就能看、能核对。

```
mixue-vs-heytea/
├── question.md        输入：一句商业问题
├── report.md          输出：完整报告（含闸门横幅与审计附录）
├── run.json           这次运行的元数据
└── audit_bundle/      可复算审计包（8 个文件）
```

## 这次运行发生了什么

- 问题：蜜雪冰城 vs 喜茶，平价茶饮进县城该不该扩？单店模型怎么算？
- 判定：`Validate`（证据不足，未上调）
- 闸门：`BLOCK`，3 项高风险落在决策区
- 证据 29 条、引文 18 条、引用支撑率 100%
- 引擎：`v0.9.87`，运行于 2026-09-17 21:21

它不是一份"完美报告"，而是一份**被自己的闸门拦下来的报告**——这正是这个项目想展示的东西：系统宁可把"不能直接拿去行动"写在最上面，也不把高风险数字藏在附录里。

## 怎么核对

```bash
cd mixue-vs-heytea/audit_bundle
python verify.py --quick     # 重探 URL 存活，只验前 10 条
python compute.py            # 从 raw/ 重算 CAGR / 同比 / 来源占比
```

两个脚本只依赖 Python 标准库，不需要安装本项目，也不需要装任何第三方包。

## 一处已知缺陷（保留原样）

`manifest.json` 里 `counts.routes = 0`。这是 v0.9.87 的一个真实缺陷：调用台账没有记录检索通道路由，所以"向几个源发起了请求"这个数读出来是 0，而报告里明明有 29 条证据。

**没有修数据，也没有改 manifest**——审计包的价值在于它记录的是当时真实的样子。这个缺陷在后续版本里已修复，见 [docs/OPERATIONS.md](../docs/OPERATIONS.md)。

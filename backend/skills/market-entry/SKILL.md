# Skill: market-entry（行业进入研究）

> 专业方法论包：把一个"能不能做/怎么进"的行业问题，用咨询级分析框架拆成可执行的市场调研。

## 适用场景
- 进入市场 / 经营诊断 / 竞品趋势跟踪

## 专业分析框架（每个维度绑定方法论，报告达到咨询公司标准）

| 维度 | 分析框架 | 说明 |
|---|---|---|
| 宏观环境 | **PEST** | 政治/经济/社会/技术 四维扫描 |
| 市场规模 | **TAM/SAM/SOM** | 总市场→可服务市场→可获取市场，人数×客单价交叉验证 |
| 竞争格局 | **波特五力** | 现有竞争/新进入者/替代品/供应商/买方议价 |
| 目标市场 | **STP** | 细分→目标→定位，输出核心客群画像 |
| 进入壁垒 | **竞争优势** | 资金/技术/牌照/渠道/品牌壁垒 |
| 单位经济 | **盈亏平衡** | 客单价/毛利/成本/回本周期 |
| 趋势风险 | **趋势扫描** | 增长趋势/颠覆变化/风险对冲 |

## 信源分级标准（L1-L5）
- L1 官方（政府/统计局/官方公告）
- L2 半官方（企业官网/权威媒体）
- L3 行业（行业报告/专业机构）
- L4 用户（社媒/评价/论坛）
- L5 推测（模型推断，必须标注）

## 输出模板（决策型交付）
报告 = 各维度模块报告（带方法论框架）+ 决策SOP（该不该做/怎么做/预算/风险）+ 数据与方法说明

## 数据边界（诚实声明）
本产品基于公开二手数据，**不含一手调研**；报告末尾主动标注，并给出"问卷≥300 / 竞品暗访 / 供应链访谈"的补充建议。

# Skill: pet-economy（宠物经济研究）

> 方法论包：换行业演示——同一个状态机，换 Skill 即换调研维度。
> 路演：先问"杭州开咖啡店"，再问"宠物经济是不是好生意" → 维度自动切换。

## 适用场景
- 宠物食品 / 宠物医疗 / 宠物用品 / 宠物店进入

## 调研维度模板（子任务骨架）
1. **市场规模** — 宠物市场规模/增速/猫狗数量/行业报告（industry）
2. **细分赛道** — 食品/医疗/用品/细分增长（industry）
3. **竞争格局** — 品牌/份额/价格带（competition）
4. **消费人群** — 养宠人群/消费习惯/复购/评价（user）
5. **进入策略** — 宠物店成本/测算/盈利（statistics）

## 信源分级标准（L1-L5）
- 与 market-entry 共用：L1官方 / L2半官方 / L3行业 / L4用户 / L5推测

## 输出模板
- 报告 = 各维度模块报告 + 决策SOP（该不该做/怎么做/预算/风险）
